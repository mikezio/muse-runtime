# About this directory

Redacted copies of actual runtime files from a live Muse instance. Personal
data is replaced with `[REDACTED]` inline; everything else is byte-for-byte.

- `HEARTBEAT.md` - the background checklist the instance works through every ~30 minutes
- `cron-job-weekly.md` - a real scheduled job definition (frontmatter + body)
- `SKILL-tts.md` - a real built-in skill file, unredacted (contains no personal data)
